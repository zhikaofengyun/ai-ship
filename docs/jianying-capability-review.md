# 剪映公开能力与批量制作对照

对照范围是剪映官网面向电脑端公开展示的专业剪辑、声音、AI 画面和创作功能，以及官网列出的应用场景。没有使用剪映内部源码或商业模型。表中保留已实现子集和需要另设素材检验的能力，以免把名称相近的工具当作通过验收。[剪映公开功能](https://www.jianying.com/)

| 官网能力 | AI Ship 实际可调用或可操作的部分 | 验收尚缺的部分 |
| --- | --- | --- |
| 视频生成、营销成片、营销文案与包装 | 市场简报与商品事实、脚本、实拍或参考图生成槽、版本化批次、独立成片和审批。选中的生成镜头可以使用多条提示和独立种子 | 商品外形、文字和运动的真值样本；商业素材通过率；自动营销包装的成片质量 |
| 蒙版与局部特效 | 矩形与椭圆遮罩写入时间线，构图之后施加。浏览器可使用，编码后能比较中心与边角的像素 | 文字、钢笔路径、跟踪、羽化等形状及第三方工程交换 |

| 调色、画质修复、补帧、智能抠像、人像修饰 | 已有构图和调色衍生版、遮罩、输出帧率设置。可对输出实际解码核查 | 色轮、HSL、曲线和浮点专业调色，学习式超分、运动补帧、人物与背景分割及多人修饰的成片验证 |

### 验收时看什么

- **画面与声音**。遮罩查边缘，转场查边界帧和音频连续性，人物或商品生成查身份、外形、文字与时间一致性。编码成功只作为这些检验的前提。[同图生成及逐帧对照](../evidence/batch-production/directed-still/README.md)
- **人工控制能否重放**。保留样片与来源版本、入出点、图层参数、关键帧、音轨、字幕及字段锁。换素材后从真实批次下载成片核查。照片横移和纵移在两份人工时间线中设置，按各自模板出片。[横移](../evidence/batch-production/controlled-photo/horizontal.mp4) · [纵移](../evidence/batch-production/controlled-photo/vertical.mp4)
- **批量使用成本**。以每个序号呈现合格、需复核和失败；单条失败可核查其原参数、原件和回执。费用、推理次数、在途并发和真实编码吞吐分别核算。[队列容量](../evidence/batch-intake-delivery/queue-capacity.json) · [实际编码](../evidence/batch-intake-delivery/render-capacity.json)
