## 五轮结论的适用范围

这五轮记录的是 Linux Chromium 的实际运行截图及约定的浏览器断言。不能用它们证明 Safari/WebKit 或实际 iPhone/macOS 的排版、触控、触觉、动态材质、透明折射、帧率或耗电；没有声称 Apple 原生逐像素复刻。没有在全部系统字体大小、对比度偏好、屏幕阅读器及滚动深度下逐项视觉检查，没有用截图判定外部模型/账号/发布平台的真机服务或每项业务功能已经完成。每轮 178 个功能和 534 条路线的程序遍历以各自主浏览器报告为准，与本审阅逐张查看的 25 张图是不同的证据。
