原始 HTML 将 23 个模块归入 8 个顶层分区。此索引保留原文分区名称和归属。每个功能先列原文要求的操作与路线，再列可实际执行的工作和剩余条件。正文供验收人员核对，产品面向操作者的界面另行实现。

## Agent协作

原文要求验收的结果为“至少一个任务可用不同能力模型协作；每角色输出有 schema 与证据；旧 lease 不能提交；人工锁不被重规划覆盖；不依赖单 Agent 自评通过。”

### C01 角色与能力编组

**原文操作**　把目标拆成职责与验收职责矩阵 → 按实际能力与资源挑选并组合执行角色 → 冻结本次团队与交接责任

**可选路线**　按能力组合角色池 ／ 异构小队串行执行与独立复核 ／ 人机混合分工

**数据流转**　Project、Workflow、Capability、Cost、TaskContract、AgentRole、SkillVersion → Workflow、AgentRole、DecisionRecord

**当前能做的事**　真实局部路径。三台独立鉴权的本地 llama.cpp 由不同角色调用。导演、复核与裁决各有冻结档案、权重摘要、返回身份、用量与实际决定。

**待验收范围**　导演与复核同属 Qwen2.5 系列，裁决使用 SmolLM2。跨团队动态换岗、合同迁移和完整视听团队仍待验证。

### C02 动态依赖规划

**原文操作**　解析目标输出和已有合法产物 → 按能力和条件生成可重排子图 → 预演每条选中路线并固定选择理由

**可选路线**　类型化DAG规划与校验 ／ 已验证子流程拼装 ／ 人工可视化编排

**数据流转**　Project、Workflow、Capability、Plan、TaskContract、AgentRole、SkillVersion、RunGraph、PreferenceProfile → Workflow、RunGraph、DecisionRecord

**当前能做的事**　真实局部路径。按固定版本的调用方工作流为每条变体生成独立子运行，绑定对应时间线，验证图与数据输入。

**待验收范围**　尚无目标驱动的任意拓扑搜索、跨图全局成本最优规划。

### C03 派工与执行租约

**原文操作**　计算真实就绪集合并预留需要的资源 → 建立一次尝试并发送可验收任务包 → 核接收回执并管理领取、续租及交回

**可选路线**　依赖就绪的优先级队列 ／ 受限串行调度 ／ 人工领取任务

**数据流转**　Workflow、Capability、Run、Cost、TaskContract、RunGraph、AgentRole、SkillVersion → Run、Event、RunGraph

**当前能做的事**　真实局部路径。持久节点检查点、租约/fencing、暂停/取消安全点和明确未知结果核对。

**待验收范围**　没有分布式多 worker 弹性调度和跨外部系统接管。

### C04 并发冲突与人工锁

**原文操作**　定位竞争对象与真实修改范围 → 比较可交换补丁与语义冲突 → 在有效写者下提交已解冲突的版本

**可选路线**　对象版本CAS与短租约 ／ 隔离分支后显式合并 ／ 单写者人工仲裁

**数据流转**　Run、Timeline、Policy、Event、RunGraph、ChangeSet、DecisionRecord → Run、Timeline、Event、ChangeSet、DecisionRecord

**当前能做的事**　真实局部路径。CAS、人工字段锁、冻结输入版本、冲突时保留版本历史。

**待验收范围**　没有所有业务实体的语义冲突合并与并发代理协商。

### C05 局部重跑与重新规划

**原文操作**　从变化字段、源区间和实际引用求影响闭包 → 生成受影响节点的替换计划 → 在安全点提交并只重跑被证明失效的范围

**可选路线**　依赖哈希与区间失效传播 ／ 阶段级检查点恢复 ／ 人工圈定重做范围

**数据流转**　Event、Workflow、Run、Timeline、RunGraph、ChangeSet、TaskContract → Workflow、Run、Event、ChangeSet、RunGraph

**当前能做的事**　真实局部路径。受版本和运行状态保护，只能改未开始节点，生成新图版本，保存前后依赖和既有检查点，恢复时执行新图。

**待验收范围**　未覆盖正在外发的副作用迁移、任意拓扑替换或全部原文重规划路线。

### C06 交接与人工接管

**原文操作**　封装可接续的最小交接包 → 将争用范围移交给指定角色或有权人员 → 验证回传结果并重新加入原任务

**可选路线**　结构化接管单 ／ 授权的替代角色接续 ／ 延期或导出工作包

**数据流转**　Run、Approval、Audit、Workflow、TaskContract、AgentRole → Run、Approval、Event

**当前能做的事**　真实局部路径。自动制作进入待审阅阶段，采用提案后可按指定时间线接管；原制作任务、批准与修订引用可查。

**待验收范围**　全类型角色交接、长时中断与跨外部平台接管仍未闭环。

### C07 共享上下文与独立复核

**原文操作**　按主张组装最小证据与反证包 → 按风险安排规则检查、独立复核或专家审阅 → 把可用结论和未解边界回给执行者

**可选路线**　证据包加独立复核角色 ／ 确定性规则与抽样人审 ／ 专家联合审阅

**数据流转**　Run、Memory、Insight、Product、TaskContract、AgentRole、DecisionRecord → Run、Insight、Approval、DecisionRecord

**当前能做的事**　真实局部路径。复核独立读取原片观测、选片区间和顺序。真实运行中复核错引时长、裁决复述同一理由，证据检查拦截两张接受票，保存原始回复。

**待验收范围**　仅验证已登记原片的时长、OCR 词和一段理由的原样重复。证据源独立性、转述抄袭和商品语义仍需核验。

### C08 目标与验收契约

**原文操作**　从原话与当前项目提取目标和不可更改条件 → 按可验收成果拆成父子任务 → 预演完成与失败条件并冻结版本

**可选路线**　按目标自动拆契约 ／ 复制已验证任务配方 ／ 人工任务单与验收清单

**数据流转**　Project、Brief、PreferenceProfile、Policy、TaskContract → TaskContract、DecisionRecord、Event

**当前能做的事**　真实局部路径。批次可以绑定固定版本的交付合同，按配置核验输出规格、时间范围、剪辑节奏及证据要求，保存各门槛结果。

**待验收范围**　尚未覆盖全部业务角色的语义验收、平台内容安全区和多供应商成本最优求解。

### C09 证据化分歧裁决

**原文操作**　按争议主张建立候选与证据矩阵 → 先筛硬约束再比较可行取舍 → 记录有范围的决定并交回验收

**可选路线**　证据矩阵与独立裁判 ／ 确定性约束先裁决 ／ 有权人员对照审阅

**数据流转**　TaskContract、DecisionRecord、Insight、Approval、AgentRole、Run → DecisionRecord、Insight、Approval

**当前能做的事**　真实局部路径。真实三个模型处理一个带原片证据的选片问题。两张接受票与原片时长字段冲突，原案禁止采用。编辑身份单镜头接管后保留旧案、审阅并成片。

**待验收范围**　尚未核验真实模型给出相反投票、开放证据权重、商品数量及复杂业务取舍。

### C10 安全局部改图事务

**原文操作**　固定补丁基线并计算精确影响 → 校验并按风险进行隔离影子测试 → 检查当前授权并选择可证明安全点 → 原子应用新版本并验证结果

**可选路线**　事务化局部补丁与安全点 ／ 从检查点建立隔离分支 ／ 暂停争议范围后人工提交

**数据流转**　ChangeSet、RunGraph、TaskContract、Run、Approval、DecisionRecord、EvaluationSuite → ChangeSet、RunGraph、Workflow、Event、Audit

**当前能做的事**　真实局部路径。受版本和运行状态保护，只能改未开始节点，生成新图版本，保存前后依赖和既有检查点，恢复时执行新图。

**待验收范围**　未覆盖正在外发的副作用迁移、任意拓扑替换或全部原文重规划路线。

### C11 异构团队部署与有界质询

**原文操作**　编组并冻结部署 → 并行派工与交接 → 有限质询与裁决 → 冻结每个关键主张的独立复核维度并记录答案暴露 → 每轮比较新增证据与剩余费用时限，决定继续或收束 → 启动前核具体循环预算与经济停止参数已明确

**可选路线**　完整异构团队 ／ 有限核心团队 ／ 人机专家补位

**数据流转**　TaskContract、AgentRole、ModelProfile、RunGraph、Capability → AgentDeployment、RunGraph、DecisionRecord

**当前能做的事**　真实局部路径。两个模型系列的三套真实权重通过三个受控服务执行固定三步质询。每角色保留身份、返回与 token 数，相同任务键复用收据，有界流程可停驻并由测试编辑接管。

**待验收范围**　仍缺动态团队拓扑、完整视听执行和效果分析团队、跨供应商实账及高负载部署。


## Harness与工具

原文要求验收的结果为“断电恢复从可验证检查点继续；相同工具请求不重复落账；模型切换有配置版本及成本变化；前后端读取同一 runtime 事件序列。”

### H01 工具输入输出契约

**原文操作**　固定本次工具和业务契约版本 → 在模型之外执行调用准入与请求记录 → 同时验结构和业务语义后接受回执

**可选路线**　版本化schema与业务校验 ／ 外部工具契约适配层 ／ 人工工作单输入输出

**数据流转**　Capability、Run、Approval、SkillVersion、TaskContract → ToolCall、Capability

**当前能做的事**　真实局部路径。64 实体合同、请求验证、类型 DAG 和 14 路线实际 operation schema。

**待验收范围**　原文大量领域字段仍开放；结构合法不证明商品事实/数量/业务意义正确。

### H02 协议与能力发现

**原文操作**　核明服务身份和协议范围 → 读取并验证可声明的能力 → 通知受影响图做兼容检查

**可选路线**　显式注册的协议适配器 ／ 固定HTTP/RPC能力清单 ／ 文件清单与人工交付协议

**数据流转**　Capability、Grant、Workflow、SkillVersion → Capability、Event

**当前能做的事**　真实局部路径。在线列出已注册的工具路线、运行时版本及每个输入输出/操作契约的指纹。

**待验收范围**　尚缺任意外部协议的自动发现、握手与未知供应商认证。

### H03 模型路由与降级

**原文操作**　先筛除不满足硬契约的模型/规则路线 → 比较合格路线的任务质量、费用与等待 → 安全切换并重验结果 → 切到规则或人工路线时核定其只承担适合的子职责

**可选路线**　已评测的能力路由 ／ 合法的备用本地或云模型 ／ 规则执行或人工判断

**数据流转**　Capability、Run、Cost、Project、TaskContract、PreferenceProfile、SkillVersion、ModelProfile → Run、ToolCall、Cost、DecisionRecord

**当前能做的事**　真实局部路径。项目可选已注册的本地模型及其固定角色。真实单导演与三个独立配置的本地模型各有请求、实际身份、测量用量与状态；非法结构或证据不符会停驻。

**待验收范围**　跨厂健康降级、变更中的候补重验、多币种和供应商实账仍缺直接证据。

### H04 上下文组装与压缩

**原文操作**　按任务确定必须钉住的事实与约束 → 按权限检索相关历史并分层组织 → 压缩到可用窗口并保存可恢复索引

**可选路线**　按任务检索与分层上下文 ／ 分阶段摘要与检查点 ／ 人工固定最小证据包

**数据流转**　Run、Memory、Workflow、Product、TaskContract、DecisionRecord、PreferenceProfile → Run、Audit

**当前能做的事**　真实局部路径。任务进入本地工作流或保存合同后，人工固定原始版本、硬约束、停止条件、未解节点和工具调用。在给定 UTF-8 字节窗口保留原文引用；重新打开会标记已变化的来源。

**待验收范围**　自动分层检索、模型专用 token 计量、多阶段自动摘要与跨执行器恢复待验。

### H05 执行沙箱与资源边界

**待验收范围**　没有 HyperFrames/其他后端的完整合同转换、能力比较或语义等效降级。

**当前能做的事**　真实局部路径。真实事件与审计查询、引用谱系、执行记录。

**待验收范围**　缺跨进程分布式 tracing、生产日志告警关联和完整敏感字段脱敏验证。

### O02 费用预留与实际结算

**原文操作**　按真实计费项估价并声明不确定性 → 对本次尝试预留并约束委派预算 → 按用量与账单结算并回收可证明余额

**可选路线**　预估预留与结算账本 ／ 固定单价包与硬次数配额 ／ 人工批准费用或延期

**数据流转**　Project、Run、ToolCall、Cost、TaskContract → Cost、Event

**当前能做的事**　真实局部路径。预算预留、未知外部调用保留占额、配置价格估算与实际账单分开。

**待验收范围**　未接供应商实际账单、跨币种结算和全部资源成本模型。

### O03 资源配额与公平调度

**原文操作**　拆分任务所需资源和公平范围 → 联合申请必要租约并选择派发窗口 → 到时重验有效性并按实况缩放

**可选路线**　分资源队列与租约 ／ 限并发批处理窗口 ／ 迁移获准资源或人工缩批

**数据流转**　Run、Cost、Capability、Account、TaskContract、AgentRole → Run、Cost、Event

**当前能做的事**　真实局部路径。批量工作按项目批次轮转，控制并发工作进程与生成窗口，登记每次生成请求，凭租约认领和恢复。普通 HTTP 服务与本机独立批次进程可分开运行，进程退出后其他领取者继续。

**待验收范围**　缺多主机调度、跨租户分层 SLA 与高分辨率成片的持续负载测量。

### O04 运行健康与质量告警

**原文操作**　按层建立有来源的观察窗口 → 结合硬护栏与任务上下文识别异常 → 路由到限定修复、停驻或人工处理

**可选路线**　分层指标与异常告警 ／ 周期探针与抽样质检 ／ 人工值守与故障工单

**数据流转**　Run、Audit、Metric、Index、Cost、RunGraph、TaskContract → Insight、Event

**当前能做的事**　真实局部路径。按项目查询真实队列积压、等待时长、过期租约与失败代码；页面展示批次与异常说明。

**待验收范围**　尚缺跨机器的主动通知、分位数 SLO 和基于生产历史的质量基线。

### O05 方案质量成本评测

**原文操作**　定义同目标可比的路线基准 → 执行代表样本或隔离影子对比 → 形成适用范围内的选路证据

**可选路线**　代表性样本基准 ／ 小规模影子对比 ／ 人工预览与保守容量估算

**数据流转**　Capability、Run、Cost、Audit、EvaluationSuite、TaskContract → Capability、Insight、DecisionRecord

**当前能做的事**　真实局部路径。相同输出范围内比较两个批次的固定样本、实际完成和用量，范围不可比时拒绝评比。

**待验收范围**　真实投放单位成本、第三方账单和长期质量基准仍待核实。

### O06 任务故障恢复与对账

**原文操作**　封存故障尝试并界定可信恢复点 → 先对账外部事实再选恢复路线 → 建立新尝试并验证接续结果

**可选路线**　检查点恢复与在途对账 ／ 换worker重做安全计算 ／ 人工核对与挂起结案

**数据流转**　Run、ToolCall、Event、Publication、Cost、Post、RunGraph、TaskContract → Run、Event、Audit、RunGraph、DecisionRecord

**当前能做的事**　真实局部路径。本地工作流检查点恢复、未知结果核对与真实产物校验。

**待验收范围**　未涵盖外部异步任务/实际账单及分布式存储故障收敛。

### O07 API与契约变化管理

**原文操作**　将官方通知与实际失配定位到版本 → 计算受影响技能、排程与图节点 → 验证替代后发布新的条件能力快照

**可选路线**　版本固定与兼容探测 ／ 已验证替代接口适配 ／ 人工通道或停用受影响功能

**数据流转**　Capability、Grant、PlatformEvent、Audit、SkillVersion → Capability、Workflow、Event、SkillVersion、ChangeSet

**当前能做的事**　真实局部路径。已登记路线采用逐项合同和底座指纹，派发前对照资格记录重新核验漂移。

**待验收范围**　外部供应商 API 行为变化和跨代迁移仍待实联。


## 工作台与扩展

原文要求验收的结果为“所有入口操作相同版本数据；拖动节点不改执行顺序；每个参数可检查、修改、重置和导出；无需顶部导航也能明确返回/定位，键盘与移动端有等价操作。”

### W01 对话与结构化控制

**原文操作**　保存原始目标并抽出可编辑字段 → 让用户直接修改范围、参数与交付条件 → 提交已明确的目标或保存可继续草稿

**可选路线**　对话生成结构草稿 ／ 表单与参数面板 ／ 导入项目配置或工作单

**数据流转**　Project、View、Capability、PreferenceProfile → Project、Workflow、View、TaskContract

**当前能做的事**　真实局部路径。制作目标、原片选择、模型路线、分镜证据、采用、渲染和结果在一个制作上下文内；原有结构化控件仍可使用。

**待验收范围**　任意业务自然语言指令、离线等价编辑及所有原生辅助技术未验。

### W02 可编辑流程与方案切换

**原文操作**　把当前流程、条件输入和实例状态放在同一可读视图 → 接受重排、插入、跳过、换路和参数调整 → 在合格状态下提交新图或分支

**可选路线**　依赖图编辑与变更预览 ／ 步骤列表与条件面板 ／ 目标驱动自动重排草稿

**数据流转**　Workflow、Capability、Run、View、RunGraph、TaskContract、ChangeSet → Workflow、View、Run、RunGraph、ChangeSet

**当前能做的事**　真实局部路径。可编辑静态 DAG 画布和参数/输入绑定，本地已支持路线可真实执行。

**待验收范围**　子流程、有界循环、全部备选路线执行和运行中安全改图没有完成。

### W03 素材与编辑联动

**原文操作**　从素材/分镜选区定位对应源与输出时间 → 把局部编辑转成可撤销的精确差异 → 预览并提交选定版本或回导包

**可选路线**　关联素材抽屉与时间线 ／ 分镜卡片式编辑 ／ 外部编辑导出导回

**数据流转**　AssetVersion、Shot、Plan、Timeline、View、ChangeSet → Timeline、Plan、View、ChangeSet

**当前能做的事**　真实局部路径。源区间、分镜提案、实际批准版本和对应时间线联动；指定时间线可人工接管，支持来源回看、工程交换与原位导出。检索结果能把原片版本和时段交给源监视器。

**待验收范围**　所有图谱层级、外部软件和跨业务回溯的端到端验收未完成。

### W04 审阅与接管收件箱

**原文操作**　按待决原因与范围建立审阅入口 → 支持原位查看证据并决定或接管 → 将决定写回对应合同并释放可继续部分

**可选路线**　按原因分类的审阅队列 ／ 作品内逐项审阅 ／ 受权限控制的审阅工作包

**数据流转**　Approval、Run、Artifact、Audit、View、TaskContract、DecisionRecord、ChangeSet → Approval、Run、View、DecisionRecord

**当前能做的事**　真实局部路径。制作提案就地复核，版本与范围检查拒绝过期版本和越界片段，使用指定时间线接管并保留普通人工草稿。

**待验收范围**　跨所有任务类型的统一收件箱、异步接管升级和权限失效后的恢复未全验。

### W05 账号发布与效果导航

**原文操作**　从真实对象身份进入关联导航 → 按所选对象展开状态、指标和来源 → 把调查动作交到对应合法入口

**可选路线**　同一身份链的关联面板 ／ 分区列表与统一搜索 ／ 官方导出对照视图

**数据流转**　Account、Publication、Metric、Usage、Artifact、View、Post、ProductionTrace → View、Insight

**当前能做的事**　真实局部路径。真实结构化工作台、素材/剪辑/交付/指标页面、偏好与无障碍样式。

**待验收范围**　完整离线等价交互、全历史视图/接管链、所有组件苹果原生光学一致性与多设备验收未完成。

### W06 插件与能力扩展

**原文操作**　把扩展来源、许可、声明与连接状态分别展示 → 按选中路径配置并验证能力 → 启用、冻结或卸载指定范围

**可选路线**　审核注册的扩展目录 ／ 管理员配置的固定适配器 ／ 人工导入导出扩展点

**数据流转**　Capability、Grant、Approval、View、SkillVersion → Capability、View、Audit、SkillVersion

**当前能做的事**　真实局部路径。固定版本的本地工作流配方通过实际资格检查后可登记、派发；拒绝未核验记录或冒充已合格的技能。

**待验收范围**　没有任意第三方代码安装、供应链签名或操作系统级插件隔离。

### W07 无障碍与多端工作区

**原文操作**　根据输入方式与偏好恢复可操作视图 → 为所有主要操作提供等价路径和清楚作用域 → 保存视图并验证跨端恢复和离线边界

**可选路线**　响应式面板与完整键盘路径 ／ 低动效列表模式 ／ 静态导出与受控操作清单

**数据流转**　View、Project、Run、PreferenceProfile → View

**当前能做的事**　真实局部路径。导航侧栏、制作/证据区和编辑器多面板可拖动或用键盘调节；六种停靠顺序、手机监视器高度与全屏回退均有双引擎操作校验。23 个模块的目录可拖宽、键盘调节、换边、收起及复位。

**待验收范围**　实体手机/Mac Safari、读屏和系统缩放、离线等价业务列表、任意独立系统窗口尚未验收。

### W08 偏好记忆与自治级别

**原文操作**　区分显式要求、临时选择与学习许可 → 在许可范围内形成或更新偏好候选 → 应用可用版本并支持纠正/暂停/删除

**可选路线**　明确设置与分层继承 ／ 有来源的偏好假设与小范围验证 ／ 会话临时选择与无长期记忆

**数据流转**　Project、PreferenceProfile、DecisionRecord、Insight、Approval、Policy → PreferenceProfile、View、Event、DecisionRecord

**当前能做的事**　真实局部路径。用户主动调整的导航宽度、制作栏宽度、剪辑面板尺寸/顺序和时间线上下位置可在当前浏览器恢复。模块目录布局按租户、用户、项目在本设备保存，经过重新打开和项目隔离测试。

**待验收范围**　仅显式本地显示偏好；未实现学习权限候选、全部作用域继承、跨设备同步或自主策略。

### W09 可编辑工作流画布与子流程

**原文操作**　构建节点和参数草稿 → 编译与无副作用预演 → 保存模板或提交变更

**可选路线**　模板组合 ／ 自由节点编排 ／ Agent生成草稿

**数据流转**　Workflow、Capability、AgentDeployment、TransformRecipe、RunGraph、ChangeSet、View → Workflow、ChangeSet、View

**当前能做的事**　真实局部路径。可编辑静态 DAG 画布和参数/输入绑定，本地已支持路线可真实执行。

**待验收范围**　子流程、有界循环、全部备选路线执行和运行中安全改图没有完成。
