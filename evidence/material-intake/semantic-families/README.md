# S04 视觉语义素材族复核

在 S04 打开「管理素材族」，选择「AI 视觉语义聚类」。选取同一项目当前可用于处理的 2–32 个已索引照片或视频，设定 0.50–1.00 的阈值。系统比较这些素材在同一版 CLIP 空间中保存的向量。照片使用原帧，视频使用索引已有的至多三帧。每帧的原始时码、画面指纹、向量指纹和素材修订均随建议保存。

两个素材之间，先为 A 的每帧求它在 B 中的最高余弦相似度，再对这些最高值取平均；从 B 到 A 重复一次，两方向均值中的较低值为素材对分数。完全链接聚类每次合并两个组内所有跨组素材对均达到阈值的族，按当前最低分最高的合并，平分时使用固定顺序。只通过一个中间素材连成链的远端素材不会被自动合并。无人确认的建议保存在 Audit 中，人工核实后才登记活动 Cluster。可逐组确认、关闭未接受建议，或在同一界面撤销活动分组。

真实 ONNX 模型在 CPU 上处理了四个文件，保存了八帧视觉向量，处理错误为零。使用阈值 0.80 获得一个待复核族。咖啡照片与从该图移动裁切、有损编码的视频，双向覆盖分为 0.949537，最佳帧余弦相似度 0.962268；照片时刻为 0 秒，视频对应 1 秒。宇航员照片和花朵视频都单列。复核 API 确认产生 Cluster v1，撤销得到同一记录的 v2。脚本用已知素材核对期望并驱动确认与撤销。

真实原图、视频及各自来源 SHA-256、四个输入版本、模型指纹、逐帧明细和两个确认修订可在[实测报告](result.json)中复核。这组素材验证一张图与其衍生视频的辨识。独立拍摄的商品、光照和品牌等类别需要增加人工标注的集合，才能估计分类准确率。三帧之外的长视频片段可能没有被采样；分数衡量画面关系，版权及来源仍须从授权链确认。

未安装本地模型、版本缺索引、素材离线、撤权或证据失效时，接口会停止并给出原因。仍可使用人工语义类目、来源链归组和逐片对照。安装本地模型后先构建画面索引，再重做建议。索引重建即使仍使用同一模型，也会在确认时核对每份帧与向量指纹。

复验命令使用项目的开发依赖、本地 CLIP 运行环境与[对应的原始样件](../result.json)。结果可保存到新路径。

```bash
python scripts/verify_semantic_families.py --sources /path/to/originals --output /tmp/semantic-run.json
python scripts/browser_semantic_families.py --engine chromium --other-photo /path/to/originals/astronaut.png --output /tmp/semantic-browser.json
python -m unittest tests.test_asset_families -v
```
